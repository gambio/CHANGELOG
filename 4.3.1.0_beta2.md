- [StyleEdit 4] StyleEdit Änderungen lassen sich nicht mehr speichern, wenn man ein Text Widget einfügt und noch eine zusätzliche Sprache hat. / StyleEdit changes can no longer be saved if you insert a text widget and have an additional language.. (67655)
