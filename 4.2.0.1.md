## 4.2.0.1 (DE)

- [Adminbereich] Non existing properties combinations are selectable although the option "Only possible values selectable" is activated. (67867)
- [Adminbereich] In the Content Manager under "Article contents" not all articles from all categories are available. (67866)
- [Core] URL von Produkten aus der E-Mail Verfügbarkeit eines Artikels sind bei aktivem SEO Boost und Sprachcode in URL nicht aufrufbar. (67900)
- [Core] Auf Servern wo der MySQL STRICT Modus mit ONLY_FULL_GROUP BY nicht deaktiviert werden kann, können keine Artikel aufgerufen werden / On servers where the MySQL STRICT mode cannot be deactivated with ONLY_FULL_GROUP BY, no products can be opened. (67868)
- [Eigenschaften] Preis im Artikel mit Eigenschaftenaufpreisen, wird nicht sofort mit Parameter combi_id sofort sichtbar, sondern erst nach einem JavaScriptaufruf / Price in the product with property surcharges, is not immediately visible with parameter combi_id. (67873)
- [Eigenschaften] Through Google Shopping Feed exported products with properties arent correctly openable // Durch Google Shopping Feed exportierte Artikel mit Eigenschaften können nicht korrekt aufgerufen werden. (67870)
- [Frontend] On some servers the detection does not work whether an image already exists or needs to be created | Auf manchen Servern funktioniert die Erkennung nicht, ob ein Bild bereits existiert oder neu erzeugt werden muss. (67869)
- [Frontend] Deactivated attribute is preselected in product details box / Deaktiviertes Attribut ist in Produkt Detail Box vorausgewählt . (67777)
- [Google Services] If products with a GX-Customizer Set are added to the cart and Google Analytics is activated, the products cannot be added. (67865)
- [Sonstiges] The most recent hub connector has to be included in the package / der neuste Hub Connector muss im Paket enthalten sein. (67894)
- [StyleEdit 4] StyleEdit Änderungen lassen sich nicht mehr speichern, wenn man ein HTML Widget einfügt und noch eine zusätzliche Sprache hat. / StyleEdit changes can no longer be saved if you insert a html widget and have an additional language.. (67871)

## 4.2.0.1 (EN)

- [Admin] Non existing properties combinations are selectable although the option "Only possible values selectable" is activated. (67867)
- [Admin] In the Content Manager under "Article contents" not all articles from all categories are available. (67866)
- [Core] The URL of products from the product availability email cannot be opened when SEO Boost and language code in URL are active. (67900)
- [Core] On servers where the MySQL STRICT mode cannot be deactivated with ONLY_FULL_GROUP BY, no products can be opened. (67868)
- [Properties] Price in the product with property surcharges is not immediately visible with parameter combi_id, but only after a JavaScript call. (67873)
- [Properties] Products with properties exported through Google Shopping Feed cannot be opened correctly. (67870)
- [Frontend] On some servers the detection does not work whether an image already exists or needs to be created. (67869)
- [Frontend] Deactivated attribute is preselected in product details box. (67777)
- [Google Services] If products with a GX-Customizer Set are added to the cart and Google Analytics is activated, the products cannot be added. (67865)
- [Miscellaneous] The most recent hub connector has to be included in the package. (67894)
- [StyleEdit 4] StyleEdit changes can no longer be saved if you insert a html widget and have an additional language. (67871)
