## 26.10.0 (DE)

- [Sicherheit]: Sicherheitsverbesserungen und Härtung der Anwendung.
- [Aktualisierung]: Shops mit einer MySQL-Version unter 8.0 können nun zuverlässig aktualisiert werden und der Updater erkennt die Updates über 26.06.0 korrekt.
- [Gambio Store]: Lehnt der Gambio Store eine Modulinstallation ab, zeigt das Installationsfenster nun den Grund dafür an.
- [Admin]: Beim Leeren des Caches wird nun auch das Verzeichnis der Modul-Komponenten zurückgesetzt, sodass neue Admin-Seiten nach einem Update sofort erreichbar sind.
- [Admin]: Versanddienstleister lassen sich nun auch speichern, wenn nicht für jede aktive Sprache eine Beschreibung hinterlegt ist.
- [Statistiken]: Die Statistiken zu angesehenen und gekauften Artikeln sind nun auch im Cloud-Shop aufrufbar.
- [Dateimanager]: Bilder und Dateien größer als 2 MB lassen sich im Rahmen der eingestellten Upload-Grenzen wieder hochladen.
- [Datensicherung]: Die Wiederherstellung einer Datensicherung funktioniert nun auch mit Tabellen, die über Fremdschlüssel verknüpft sind, etwa durch Module von Drittanbietern.
- [Datensicherung]: Die Wiederherstellung meldet nun zuverlässig einen Fehler, wenn die Sicherungsdatei fehlt oder beschädigt ist.
- [Datenschutz]: Das Löschen personenbezogener Kundendaten wird nun auch dann vollständig ausgeführt, wenn zu einem Widerruf keine numerische Postleitzahl gespeichert ist.
- [Kundenkonten]: Persönliche Daten im Kundenkonto lassen sich nun auch speichern, wenn das Theme kein Firmenfeld anzeigt.
- [Barrierefreiheit]: In den Kontoformularen der Themes Malibu und Honeygrid ist die Beschriftung „Telefon" nun korrekt mit dem Telefonfeld verknüpft.
- [Widerrufsrecht]: Die Widerrufs-E-Mail verwendet nun im Modul und im Shop denselben Wortlaut.
- [Garantielabel]: Das Garantielabel wird nun mit weißem Hintergrund angezeigt und skaliert in der mobilen Ansicht korrekt.
- [Garantielabel]: Der Hinweis zur gesetzlichen Gewährleistung ist in der Kaufbox nun gut lesbar, einschließlich QR-Code.
- [Slider]: Slider blättern standardmäßig nun nicht mehr automatisch weiter.
- [StyleEdit]: Die Vorschau in StyleEdit bleibt nun auch bei mehreren gleichzeitigen Anfragen fehlerfrei.
- [Protokollierung]: Im Live-Betrieb werden Protokolleinträge nun ohne erweiterte Anfragedaten geschrieben, sodass die Log-Dateien kompakt bleiben.
- [Lizenzen]: Schriftarten und Lizenzen wurden bereinigt, um eine vollständig frei lizenzierte Auslieferung sicherzustellen.
- [Garantielabel-Modul]: Für ältere Shopversionen ist das EU-Garantie- und Gewährleistungslabel nun als Modul erhältlich; beim Update auf eine Shopversion mit integrierter Funktion werden die Einstellungen automatisch übernommen.

## 26.10.0 (EN)

- [Security]: Security improvements and hardening of the application.
- [Update]: Shops running a MySQL version below 8.0 can now be updated reliably, and the updater correctly detects updates beyond 26.06.0.
- [Gambio Store]: If the Gambio Store rejects a module installation, the installation dialog now shows the reason.
- [Admin]: Clearing the cache now also resets the module component registry, so new admin pages are available immediately after an update.
- [Admin]: Parcel services can now be saved even if a description is not stored for every active language.
- [Statistics]: The statistics for viewed and purchased products are now also available in the cloud shop.
- [File Manager]: Images and files larger than 2 MB can be uploaded again within the configured upload limits.
- [Database Backup]: Restoring a database backup now also works with tables linked by foreign keys, for example by third-party modules.
- [Database Backup]: The restore now reliably reports an error if the backup file is missing or corrupt.
- [Data Protection]: Deleting a customer's personal data now completes fully, even if a withdrawal has no numeric postcode stored.
- [Customer Accounts]: Personal data in the customer account can now be saved even if the theme does not show a company field.
- [Accessibility]: In the account forms of the Malibu and Honeygrid themes, the "Telephone" label is now correctly linked to the telephone field.
- [Right of Withdrawal]: The withdrawal email now uses the same wording in the module and in the shop.
- [Warranty Label]: The warranty label is now displayed with a white background and scales correctly in the mobile view.
- [Warranty Label]: The notice on the legal guarantee is now clearly readable in the buy box, including the QR code.
- [Slider]: Sliders no longer advance automatically by default.
- [StyleEdit]: The StyleEdit preview now stays error-free even with several simultaneous requests.
- [Logging]: In live operation, log entries are now written without extended request data, keeping log files compact.
- [Licenses]: Fonts and licenses have been cleaned up to ensure a fully freely licensed distribution.
- [Warranty Label Module]: The EU guarantee and warranty label is now available as a module for older shop versions; when updating to a shop version with the built-in feature, the settings are carried over automatically.
