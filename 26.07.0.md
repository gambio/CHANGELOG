## 26.07.0 (DE)

- [Sicherheit]: Sicherheitsverbesserungen und Härtung der Anwendung.
- [Module Center]: Die Modulliste bleibt auch dann nutzbar, wenn der Gambio Store nicht erreichbar ist (z. B. bei Wartung oder Verbindungsproblemen). Lokal installierte Module werden weiterhin angezeigt.
- [Module Center]: Module, deren Herstellerverzeichnis einen Bindestrich enthält, werden nach der Installation über den Gambio Store wieder korrekt in der Modulliste angezeigt.
- [Gambio Store]: Fehlerhafte Anfragen an den Gambio Store werden im Shop sauber abgefangen und führen nicht mehr zu Anzeigefehlern.
- [Admin]: Ein Hinweisdialog, der sich nicht schließen ließ und auf jeder Admin-Seite erneut erschien, wird jetzt korrekt ausgeblendet.
- [REST-API]: Das Löschen von Produktvarianten über die API führt bei Produkten ohne Varianten nicht mehr zu einem Fehler.

## 26.07.0 (EN)

- [Security]: Security improvements and hardening of the application.
- [Module Center]: The module list remains usable even when the Gambio Store is unreachable (e.g. during maintenance or connectivity issues). Locally installed modules are still displayed.
- [Module Center]: Modules whose vendor directory contains a hyphen are displayed correctly in the module list again after installation via the Gambio Store.
- [Gambio Store]: Faulty requests to the Gambio Store are now handled cleanly in the shop and no longer cause display errors.
- [Admin]: A notification dialog that could not be dismissed and reappeared on every admin page is now closed correctly.
- [REST API]: Deleting product variants via the API no longer causes an error for products without variants.
