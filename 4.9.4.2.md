## 4.9.4.2 (DE)

- [Adminbereich] Sendungsnummern werden nicht mehr mehrfach zu einer Bestellung hinzugefügt, wenn der Button versehentlich mehrfach angeklickt wird.
- [Afterbuy] Beim Import von Artikeln aus Afterbuy bleibt die Mindestbestellmenge nun erhalten und wird nicht überschrieben.
- [Core] ProductListing Log wird jetzt nur noch im Entwicklungsmodus geschrieben
- [Partner] DHL Warenpost wurde durch DHL Kleinpaket ersetzt
- [REST-API] Via API können Produkten jetzt auch Bilder zugewiesen werden, die in Unterordnern liegen
- [Zusatzoptionen] Preise werden jetzt wieder aktualisiert, wenn man eine Zusatzoption mit Aufpreis auswählt

## 4.9.4.2 (EN)

- [Admin] Tracking numbers are no longer added multiple times to an order when the button is accidentally clicked several times.
- [Afterbuy] When importing products from Afterbuy, the minimum order quantity is now retained and is not overwritten.
- [Core] The ProductListing log is now only written in development mode.
- [Partner] DHL Warenpost has been replaced by DHL Kleinpaket.
- [REST-API] Via API, products can now also be assigned images that are located in subfolders.
- [Additional Options] Prices are now updated again when selecting an additional option with a surcharge.
