## 5.0.1.0 (DE)

- [ResponsiveFilemanager]: Thumbnail-Generierung für Dateien und Ordner mit Sonderzeichen im Namen (z.B. Leerzeichen) korrigiert
- [GambioAdmin]: Fehler behoben, bei dem die Länderzonen-Auswahl in den Einstellungen nicht funktionierte
- [GambioShop]: Swiperfunktion für Artikellisten korrigiert, sodass alle Artikel sowohl in der Desktop- als auch in der mobilen Ansicht vollständig durchgescrollt werden können
- [Checkout]: Hinweis „Steuerfreie innergemeinschaftliche Lieferung. Steuerschuldnerschaft des Leistungsempfängers" wird bei Bestellungen mit mehreren Steuersätzen nun nur noch einmal angezeigt statt mehrfach pro Steuersatz
- [Gambio Hub]: Fehlende Apple-Domain-Assoziationsdatei hinzugefügt, die für die Aktivierung von Apple Pay über PayPal erforderlich ist
- [Cache]: Ein kritischer Fehler wurde behoben, wenn Dateien nicht lesbar waren
- [Produktbewertungen]: Fehlerhaften Kategorie-Link im Breadcrumb beim Schreiben einer Produktbewertung korrigiert
- [SEO]: Neue Einstellung für MetaTag auf Folgeseite bei Kategorien hinzugefügt (index, follow)

## 5.0.1.0 (EN)

- [ResponsiveFilemanager]: Fixed thumbnail generation for files and folders with special characters in the name (e.g. spaces)
- [GambioAdmin]: Fixed an error where the country zone selection in the settings did not work
- [GambioShop]: Fixed the swiper function for product lists so that all products can be fully scrolled through in both the desktop and mobile view
- [Checkout]: The notice "Tax-free intra-community supply. Reverse charge for the recipient of the service" is now displayed only once for orders with multiple tax rates instead of multiple times per tax rate
- [Gambio Hub]: Added the missing Apple domain association file required for activating Apple Pay via PayPal
- [Cache]: Fixed a critical error that occurred when files were not readable
- [Product Reviews]: Fixed an incorrect category link in the breadcrumb when writing a product review
- [SEO]: Added a new setting for the meta tag on subsequent pages of categories (index, follow)
