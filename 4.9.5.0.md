- [Checkout] Die SEPA-Daten werden nun bis zum Prozessende in allen Bestellungsschritten gespeichert.

- [Core] Artikeldetailseite: Wenn dem Hersteller des Artikels kein Bild zugewiesen wurde, wird nun stattdessen ein Hyperlink angezeigt
- [Adminbereich] Filter für die Bestellübersicht verbessert
- [SEO] robots.txt um Disallow: /*?srsltid erweitert, um doppelten Content bei Google zu vermeiden
- [Core] "Bezahlen mit Amazon"-Modul kann weiterhin verwendet werden, wenn es bereits installiert ist, kann jedoch nicht mehr neu installiert werden
- [Afterbuy] Import von Afterbuy Produkten verbessert
- [Core] Breadcrump-Link zum Produkt bei Produktbewertung hinzugefügt
- [Core] Verbesserte Fehlerbehandlung bei nicht existierenden Produkten
- [Checkout] Paketshops und Packstationen sind als Versandadresse nutzbar
- [Core] Dateimanager aktualisiert
- [Frontend] Artikel werden auf mobilen Geräten nicht mehr in den Warenkorb gelegt, wenn man mit dem Finger über den Warenkorbbutton scrollt (wird im nächsten Update verbessert)
- [Gutscheine] Eingeschränkte Kupons auf Artikel werden jetzt korrekt behandelt
- [Core] Schutz vor automatisierten Registrierungen durch Skripte erhöht
- [Core] Verbesserte Handhabung beschädigter Bild-Dateien
- [Core] Es wird kein Fehler mehr geloggt, wenn man die popup_content.php ohne Parameter aufruft
- [Adminbereich] Performance des Filters in der Bestellübersicht verbessert
- [Core] Zeitgesteuerte Aufgabe "Log-Dateien löschen" für Dateien, die älter sind als zwei Tage, ist jetzt standardmäßig aktiv, wenn dieser Wert bisher nicht gesetzt wurde
- [Checkout] Ladezeit des Warenkorbes verbessert, wenn man sehr viele GX-Customizer Artikel hat
- [Malibu] Bilder der Standardstartseite um alt-Attribute erweitert für BFSG
- [StyleEdit 4] Theme-Upload in StyleEdit 4 funktioniert nun auch mit einem PHP memory_limit von -1
- [REST-API] API Auth Token kann nun bei 1und1 verwendet werden
- [REST-API] Neuen API-Endpunkt hinzugefügt: shop-config
- [Sonstiges] USt-ID-Formate aktualisiert
- [Adminbereich] Sitemap kann jetzt auch generiert werden, wenn sämtliche Kategorien deaktiviert sind
- [Dateimanager] Im Log werden jetzt weniger Warnungen angezeigt, wenn ein Bild beschädigt ist
- [Adminbereich] Reihenfolge der Menüpunkte im Dropdown bei Artikelübersicht an Reihenfolge der Tabs in Artikelbearbeitung angepasst
- [Partner] IPayment: Konfiguration wurde repariert; Zahlungen sind wieder möglich
- [Adminbereich] Unterstützung für WebP Bilder
- [Frontend] Verbesserungen für die Barrierefreiheit
- [Frontend] Das Format für das Geburtsdatum wird jetzt je nach Sprache korrekt definiert

## 4.9.5.0 (EN)

- [PayOne] PayOne modules have been removed
- [Heidelpay] Heidelpay modules have been removed
- [StyleEdit4] When editing widgets such as tabs or carousel, the favorite marking now stays on the element, not on the row
- [Afterbuy] The VAT from bulky goods surcharges is now correctly transmitted from Gambio to Afterbuy.
- [Admin] English option texts for the terms "Age group" and "Gender" are now used in the English Admin Dashboard.
- [Checkout] The SEPA data is now saved until the end of the process in all order steps.
- [Checkout] If the module "Product condition notice during the order process" is installed and configured so that the corresponding texts must be confirmed, these are now visually marked as mandatory fields
- [Core] Product detail page: The add-to-cart button is now disabled when a 0 is entered in the quantity input field.
- [Core] Product detail page: If no image has been assigned to the manufacturer of the product, a hyperlink is now displayed instead
- [Admin] Improved filter for the order overview
- [SEO] robots.txt extended with Disallow: /*?srsltid to avoid duplicate content on Google
- [Core] The "Pay with Amazon" module can still be used if it is already installed, but can no longer be reinstalled
- [Afterbuy] Improved import of Afterbuy products
- [Core] Added breadcrumb link to the product in product reviews
- [Core] Improved error handling for non-existent products
- [Checkout] Parcel shops and packing stations can be used as a shipping address
- [Core] Updated file manager
- [Frontend] Products are no longer added to the cart on mobile devices when scrolling over the add-to-cart button with a finger (will be improved in the next update)
- [Coupons] Restricted coupons on products are now handled correctly
- [Core] Increased protection against automated registrations by scripts
- [Core] Improved handling of corrupted image files
- [Core] No error is logged anymore when popup_content.php is called without parameters
- [Admin] Improved performance of the filter in the order overview
- [Core] The scheduled task "Delete log files" for files older than two days is now active by default if this value was not set before
- [Checkout] Improved loading time of the shopping cart when you have a large number of GX-Customizer products
- [Malibu] Images of the default start page extended with alt attributes for BFSG
- [StyleEdit 4] Theme upload in StyleEdit 4 now also works with a PHP memory_limit of -1
- [REST-API] API auth token can now be used with 1und1
- [REST-API] Added new API endpoint: shop-config
- [Miscellaneous] Updated VAT ID formats
- [Admin] Sitemap can now also be generated when all categories are disabled
- [File Manager] Fewer warnings are now displayed in the log when an image is corrupted
- [Admin] Order of the menu items in the dropdown of the product overview adjusted to the order of the tabs in the product editing
- [Partner] IPayment: Configuration has been fixed; payments are possible again
- [Admin] Support for WebP images
- [Frontend] Improvements for accessibility
- [Frontend] The format for the date of birth is now correctly defined depending on the language
