## 4.4.0.3 (DE)

- [Admin Dashboard] The statistics on the Gambio Admin start page should be improved | Die Statistiken auf der Gambio Admin Startseite sollten überarbeitet werden. (68740)
- [Core] An HTTP request to the shop sometimes establishes too many database connections | Ein HTTP-Request an den Shop baut teils zu viele Datenbankverbindungen auf. (68814)
- [Frontend] Bei Wahl der Versandart Selbstabholung wird die Lieferadresse nicht auf die Shopbetreiberadresse gesetzt und damit häufig bei Auslandskunden ein falscher Mehrwersteuersatz berechnet. (68815)
- [Security] Sicherheitsverbesserungen und Härtung der Anwendung.
- [StyleEdit 4] Wenn man im StyleEdit4 eine Produktliste mit einer Kategorie einfügen will und die Artikel keine Lieferzeit haben, werden keine Artikel angezeigt. (68817)

## 4.4.0.3 (EN)

- [Admin Dashboard] The statistics on the Gambio Admin start page should be improved. (68740)
- [Core] An HTTP request to the shop sometimes establishes too many database connections. (68814)
- [Frontend] When choosing the shipping method self-collection, the delivery address is not set to the shop operator address, which often results in an incorrect VAT rate being calculated for foreign customers. (68815)
- [Security] Security improvements and hardening of the application.
- [StyleEdit 4] When you want to insert a product list with a category in StyleEdit4 and the products have no shipping time, no products are displayed. (68817)
