## 4.7.2.0 (DE)

- [Admin Dashboard] Improve texts and navigation on customer management pages for a better user experience. (70197)
- [Admin Dashboard] Fehler 500 auf Dashboard wenn Bestellung ohne Besucher existiert | Error 500 on dashboard if an order without any visitors exists. (70196)
- [Admin Dashboard] Update delete customer modal to be able to delete customer personal data too. (70191)
- [Adminbereich] Beim Anlegen eines Kunden sollte die Kundennummer vorausgefüllt sein | When creating a customer, the customer number should be prefilled. (70088)
- [Adminbereich] Phpminiadmin throws unexpected error in Php 8.1. (70162)
- [Adminbereich] Auf der "Eigene Fehlerseiten"-Seite wird nur der Inhalt der Fehlerseiten zu einer Sprache angezeigt | On the "Own Error Pages" page only the content of the error pages for one language is displayed. (70188)
- [Adminbereich] Widerrufe können nicht geladen werden, wenn die customer_id 0 und nicht null ist | Withdrawals cannot be loaded if the customer_id is 0 and not null. (70182)
- [Adminbereich] In den Einstellungen im Gambio Admin führt die Suche zu falsch ausgefüllten Feldern | In the settings in the Gambio Admin, the search leads to incorrectly filled fields. (70186)
- [Checkout] Artikelversandkosten (gambioultra) können nicht berechnet werden, wenn man PHP 8 benutzt | Product shipping costs (gambioultra) can not be calculated when using PHP 8. (70183)
- [Core] Änderungen der eigenen Fehlerseiten werden nicht zuverlässig angewandt | Changes to own error pages are not applied reliably. (70064)
- [Frontend] Wenn ein Artikel auf "Nicht käuflich" steht, dann wird zwar der Preis auf der Artikeldetailseite angezeigt, aber mit Varianten wird dann wieder "nicht käuflich" nach der Auswahl angezeigt. (70170)
- [Frontend] Das Auge-Symbol in Passwortfeldern sollte ein Aktions- und kein Status-Icon sein | Change toggle password view button from state to action. (70190)
- [Frontend] When selecting a variant on the product detail page, the first image of an associated image collection should be preselected | Bei der Auswahl einer Variante auf der Produktdetailseite soll das erste Bild einer zugehörigen Bildsammlung vorausgewählt werde. (70194)
- [Frontend] Ein Kupon mit Erstattung der Versandkosten berechnet die MwSt. falsch, sofern der Warenkorb mehrere MwSt.-Sätze enthält | A coupon with refund of shipping costs calculates VAT incorrectly if the shopping cart contains multiple VAT rates. (70195)
- [HubConnector] Integration Hub-Connector v1.23.5. (70185)
- [Sonstiges] move.php should be a known file to the gambio_updater | move.php sollte eine bekannte Datei für denn gambio_updater sein. (70187)
- [Updater] Datei dependent.php wird vom Updater nicht verarbeitet | File dependent.php is not processed by the updater. (70179)
- [Updater] Unnötige Schritte im Updater sollten vermieden werden | Unnecessary steps in the updater should be avoided. (70171)
