- [Sicherheit]: Sicherheitsverbesserungen und Härtung der Anwendung, inklusive aktueller security patches. 
- [Systemvoraussetzungen]: Gambio benötigt nun PHP 8.2 oder höher – für eine aktuelle und sichere Basis.
- [Aktualisierung]: Der Updater zeigt nun zuverlässig an, dass die PHP-Version erhöht werden muss, wenn diese zu niedrig ist.
- [StyleEdit]: Der Theme-Editor StyleEdit wurde modernisiert und arbeitet nun schneller und stabiler.
- [StyleEdit]: Das Bearbeiten von Themes funktioniert nun zuverlässig – Optionen, Auswahlfelder und Fehlermeldungen arbeiten einwandfrei.
- [StyleEdit]: Ein neuer Hinweis weist nun darauf hin, dass das Öffnen von StyleEdit in einem zweiten Tab die laufende Sitzung beendet.
- [StyleEdit]: Die Theme-Auswahl wurde aufgeräumt; das Hochladen eigener Themes ist weiterhin möglich.
- [Content Manager]: Eingebettete Videos (z. B. YouTube) werden nun wieder zuverlässig abgespielt.
- [Kasse]: Neue Liefer- oder Rechnungsadressen werden im Checkout nun automatisch ausgewählt.
- [Artikel]: Zusätzliche Produktfelder werden nun zuverlässig gespeichert, korrekt angezeigt und beim Duplizieren vollständig übernommen.
- [Versand]: DPD und Deutsche Post werden im Admin-Bereich nun korrekt und eindeutig benannt.
- [Module Center]: Gambio-eigene Module werden nun zuverlässig mit „Gambio" als Hersteller angezeigt.
- [Icons & Schriftarten]: Icons in Shop und Admin stammen nun einheitlich aus Font Awesome 5 Free (5.15.4), die Länderflaggen aus flag-icon-css 3.5.0.


## 26.08.0 (EN)

- [Security]: Security improvements and hardening of the application, including latest security patch. 
- [System requirements]: Gambio now requires PHP 8.2 or higher – for a current and secure foundation.
- [Update]: The updater now reliably shows that the PHP version must be raised if it is too low.
- [StyleEdit]: The StyleEdit theme editor has been modernised and now runs faster and more stably.
- [StyleEdit]: Editing themes now works reliably – options, selection fields and error messages all work correctly.
- [StyleEdit]: A new notice now points out that opening StyleEdit in a second tab ends the current session.
- [StyleEdit]: The theme chooser has been tidied up; uploading your own themes is still possible.
- [Content Manager]: Embedded videos (e.g. YouTube) now play reliably again.
- [Checkout]: New delivery or billing addresses are now selected automatically during checkout.
- [Products]: Additional product fields are now saved reliably, displayed correctly and fully carried over when duplicating.
- [Shipping]: DPD and Deutsche Post are now labelled correctly and clearly in the admin area.
- [Module Center]: Gambio's own modules are now reliably shown with "Gambio" as the vendor.
- [Icons & Fonts]: Icons across the shop and admin now come uniformly from Font Awesome 5 Free (5.15.4), and the country flags from flag-icon-css 3.5.0.
- [Themes & CSS]: The new SCSS compiler validates CSS more strictly – if a theme no longer compiles cleanly after the update, the custom CSS should be checked for invalid rules.
