- [Adminbereich] Email options can partly not be saved | E-Mail-Optionen können teils nicht gespeichert werden. (68242)
- [Adminbereich] Speichern-Button unter den Cross Sellings eines Artikels fehlerhaft / Faulty UX when creating a cross-selling article. (68243)
- [Adminbereich] Content Manager: Teilweise Sichtbar Banner nicht mehr da | Partly Visible banner is gone. (68379)
- [Adminbereich] Paketleergewicht kann nicht mit 0 abgespeichert werden / Package Tare Weight can not be saves as 0. (68347)
- [Adminbereich] English content manager entries can't be edited when english is deactivated in frontend / englische Content-Managereinträge lassen sich nicht editieren wenn Englisch im Frontend deaktiviert wurde. (68346)
- [Adminbereich] Anlegen von Artikel ist langsam wenn man viele Artikel hat und SEO BOOST URLs aktiviert hat / Creating products is slow if you have many products and have SEO BOOST URLs enabled. (68246)
- [Adminbereich] Wenn man viele GX-Customizer Artikel hat und eine Bestellung mit diesen durchführt, dann kann die Bestelldetailseite nicht immer aufgerufen werden. (68192)
- [Checkout] Warenkorb ist nicht aufrufbar, wenn man als Versandland "Kongo" eingestellt hat / Shopping cart cannot be opened if you have set "Congo" as the shipping country. (68256)
- [Cookie Consent] Hinweismeldung im Browser für ein ungültiges Cookie, was in zukünftigen Browsern abgelegt werden kann / Warning message in the browser for an invalid cookie, which can be dropped in future browsers. (68224)
- [Core] Depricated Warnungen im admin-Log bezüglich DBAL 3.0 vermeiden / Avoid depricated warnings in admin log regarding DBAL 3.0. (68228)
- [Core] rel="noopener" im Copyright Footer ergänzen / add rel="noopener" to the copyright footer. (68249)
- [Core] Wenn in den Konfigurationsdateien noch auskommentierte Datenbankdaten stehen, werden diese fälschlicher Weise vom Shop benutzt um eine Verbindung herzustellen. (68262)
- [Eigenschaften] Properties weight isn't displayed on products page / Eigenschaftengewicht wird nicht auf der Artikelsdetailseite dargestellt. (68300)
- [Eigenschaften] Man kann Bilder aus Kollektionen löschen obwohl diese noch in einem anderen Artikel mit der selben Kollektion genutzt werden / You can delete images from collections even though they are still used in another product with the same collection. (68332)
- [Eigenschaften] Property combination dropdown mode 2 does not consider deactivated stock options | Dropdown Modus 2 in Eigenschaftenkombinationen ignorieren deaktivierte Lageverwaltung Einstellungen. (68244)
- [Eigenschaften] Eigenschaften-Aufpreise werden nicht vor Auswahl angezeigt | Properties surcharges are not displayed before selection. (67888)
- [Frontend] Woanders günstiger ist nicht aufrufbar, wenn man Artikel mit Attributen nutzt / price offer is not usable when using products with attributes. (68257)
- [Frontend] Bei Fragen zum Produkt werden die Eigenschaften / Attribute nicht mehr übermittelt / For questions about the product, the properties / attributes are no longer transmitted. (68307)
- [Frontend] Too little feedback when adding a product to the cart from a category. (66280)
- [Google Services] google_export_availability ist nicht Sprachabhänig / google_export_availability are not language dependent. (68238)
- [Gutscheine] Willkommensrabatt-Couponcode wird als versandter Gutschein gespeichert | New signup discount coupon gets saved as voucher. (68231)
- [Malibu] Malibu ignores color settings in vertical category navigation / Malibu-Theme ignoriert hover und aktive-Farbeinstellungen in der vertikalen Navigation. (67065)
- [Malibu] Auf der Artikeldetailseite werden Cross-Selling-Artikel nicht für alle Breakpoints korrekt dargestellt | Cross-selling products are not displayed correctly for all breakpoints on the product detail page. (68032)
- [Security] Sicherheitsverbesserungen und Härtung der Anwendung.
- [Sonstiges] GX-Customizer can lose its tabs / GX-Customizer kann seine Tabs verlieren. (68382)
- [Sonstiges] Weiterleitungsregel für verschobenen Shop sollte möglich sein | Redirection rule for moved shop should be possible. (68248)
- [Sprachsystem] English language in backend has buttons in the settings still labeled in German | Trotz englischer Sprache im Backend sind "aufrufen"-Buttons in den Einstellungen weiterhin auf Deutsch beschriftet. (68388)
