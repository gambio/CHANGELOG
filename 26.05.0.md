## 26.05.0 (DE)

- [Widerrufsrecht]: Neuer rechtskonformer Widerrufs-Button gemäß § 356a BGB / EU-Richtlinie 2023/2673 (verpflichtend ab 19. Juni 2026). Im Malibu- und Honeygrid-Theme wird im Footer ein dauerhaft sichtbarer „Widerrufsrecht"-Link/Button angezeigt, der zu einem Login-freien Widerrufsformular unter `/withdrawal.php` führt. Eingeloggte Kunden können den Widerruf direkt aus der Bestellübersicht starten, das Formular wird mit Konto- und Bestelldaten vorbefüllt. Nach dem Absenden erhält der Kunde eine automatische Bestätigungsmail mit allen erfassten Angaben und Eingangszeitstempel. Hinweis: Der Button ist standardmäßig nur in neu aufgesetzten Shops aktiv. Bestehende Shop-Betreiber müssen die Sichtbarkeit und die Styling-Anpassungen selbst vornehmen; eine ausführliche Anleitung dazu wird bereitgestellt.
- [Module Center]: Modul-Versionsinformationen werden nun direkt aus dem `GXModules`-Verzeichnis jedes Moduls gelesen statt aus dem zentralen `/version_info/`-Ordner. Modulversionen und Store-IDs bleiben dadurch über Cloud-Backups und Shop-Updates hinweg erhalten und bleiben in der Modul-Center-Übersicht sichtbar.
- [Sicherheit]: Sicherheitsverbesserungen und Härtung der Anwendung.
- [Rechte & Rollen]: Rollenbasierte Berechtigungen wurden korrigiert. Nutzer mit einer reinen Lese-Rolle können Backend-Inhalte nicht mehr bearbeiten oder löschen. Die Beschränkungen greifen jetzt konsistent in allen Admin-Bereichen.
- [StyleEdit]: Theme-Export funktioniert nun auch für Themes ohne `contentzones`-Ordner bzw. ohne Content-Zone-JSON-Dateien.
- [StyleEdit]: Theme-Export für Themes mit Content-Zone-Widgets vom Typ `url` (z. B. Link-Widgets im Malibu-Theme) läuft wieder ohne Serverfehler durch.
- [GambioShop]: Kundengruppenchecks greifen jetzt global, sodass Kategorien einer ausgeblendeten Kundengruppe nicht mehr über die direkte URL aufrufbar sind.
- [GambioShop]: Der Preisfilter in der Kategorieansicht arbeitet konstant zuverlässig.
- [GambioShop]: Timer für Download-Produkte laufen wieder korrekt.
- [GambioShop]: Der globale Startseitenfilter löst keine Fehler mehr aus.
- [Malibu]: Der Gutschein-„Einlösen"-Button im Warenkorb ist nun standardmäßig sichtbar. Kunden müssen nicht mehr über den Bereich hovern, um den Gutscheincode abzuschicken.
- [Gutscheine]: Die Datumsauswahl im Admin wurde korrigiert. Gutscheine mit einem „Gültig ab"-Datum in vergangenen Jahren können bearbeitet werden, ohne dass das Jahr stillschweigend nach vorn verschoben wird. Nicht angefasste Datumsfelder bleiben beim Bearbeiten unverändert.
- [Artikeldetailseite]: Überhöhter Abstand zwischen den Tabs in der mobilen Ansicht wurde behoben. Das mobile Layout wirkt wieder kompakt und sauber.
- [Produkte]: Automatisch generierte Eigenschafts-Kombinationen übernehmen das Gewicht jetzt korrekt aus den Eigenschaftswerten.
- [Datenbank]: Die Länge des `city`-Felds in den Tabellen `orders`, `address_book` und `invoices` wurde von 32 auf 64 Zeichen erhöht.

## 26.05.0 (EN)

- [Right of Withdrawal]: New legally compliant withdrawal button in accordance with § 356a BGB / EU Directive 2023/2673 (mandatory from June 19, 2026). In the Malibu and Honeygrid themes, a permanently visible "Right of Withdrawal" link/button is shown in the footer, leading to a login-free withdrawal form at `/withdrawal.php`. Logged-in customers can start the withdrawal directly from the order overview; the form is pre-filled with account and order data. After submission, the customer receives an automatic confirmation email with all entered details and a timestamp of receipt. Note: By default, the button is only active in newly set up shops. Existing shop operators must enable visibility and apply the styling adjustments themselves; detailed instructions are provided.
- [Module Center]: Module version information is now read directly from each module's `GXModules` directory instead of the central `/version_info/` folder. As a result, module versions and store IDs are preserved across cloud backups and shop updates and remain visible in the Module Center overview.
- [Security]: Security improvements and hardening of the application.
- [Rights & Roles]: Role-based permissions have been corrected. Users with a read-only role can no longer edit or delete backend content. The restrictions now apply consistently across all admin areas.
- [StyleEdit]: Theme export now also works for themes without a `contentzones` folder or without content zone JSON files.
- [StyleEdit]: Theme export for themes with content zone widgets of type `url` (e.g. link widgets in the Malibu theme) now completes again without a server error.
- [GambioShop]: Customer group checks now apply globally, so categories of a hidden customer group can no longer be accessed via the direct URL.
- [GambioShop]: The price filter in the category view now works consistently and reliably.
- [GambioShop]: Timers for download products run correctly again.
- [GambioShop]: The global home page filter no longer triggers errors.
- [Malibu]: The voucher "Redeem" button in the cart is now visible by default. Customers no longer need to hover over the area to submit the voucher code.
- [Vouchers]: The date picker in the admin has been fixed. Vouchers with a "Valid from" date in past years can be edited without the year being silently shifted forward. Untouched date fields remain unchanged when editing.
- [Product Detail Page]: Excessive spacing between the tabs in the mobile view has been fixed. The mobile layout looks compact and clean again.
- [Products]: Automatically generated property combinations now correctly take the weight from the property values.
- [Database]: The length of the `city` field in the `orders`, `address_book` and `invoices` tables has been increased from 32 to 64 characters.
